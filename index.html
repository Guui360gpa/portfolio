Sobre mim

Sou estudante de Desenvolvimento de Software Multiplataforma na FATEC Osasco, com foco em back-end e interesse especial pelo ecossistema Java e Spring. Minha jornada é guiada pela curiosidade de entender como as coisas funcionam por trás das aplicações: gosto de entender não só como implementar, mas as decisões técnicas envolvidas, buscando soluções bem estruturadas, eficientes e de fácil manutenção.

Trabalho principalmente com Java, Spring Boot, Spring Data JPA, Hibernate e Maven, aplicando POO, Design Patterns, arquitetura em camadas e princípios de segurança. Também explorei Spring Security, JWT, Flyway, JUnit e Mockito. Tenho interesse em arquitetura de software, Engenharia de Software e Inteligência Artificial.

GET /projetos/gestao-academica

Sistema de Gestão Acadêmica

roda localmente

API REST com frontend que gerencia alunos, professores, cursos, turmas e matrículas. Nasceu como aplicação de terminal e evoluiu em três versões:

  1. v2.0.0API REST em camadas, com DTOs.
  2. v3.0.0JWT stateless, papéis ADMIN/USUARIO e frontend em HTML, CSS e JS puro.
  3. v3.1.0Docker Compose com backend, frontend e PostgreSQL, Nginx como proxy reverso e build multi-stage.
  • Soft delete, bloqueio de matrícula duplicada e bloqueio de desativação de professor ou curso com turma ativa.
  • GlobalExceptionHandler com respostas padronizadas.
  • Java 25
  • Spring Boot 4.0.6
  • Spring Data JPA/Hibernate
  • Spring Security
  • JJWT
  • PostgreSQL
  • Bean Validation
  • Lombok
  • Maven
  • Docker Compose
  • Nginx
